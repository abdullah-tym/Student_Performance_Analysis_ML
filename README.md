# 🎓 Student Performance Analysis & Machine Learning Prediction

## 📌 Project Overview
An end-to-end data science and machine learning project focused on analyzing student academic performance and behavioral patterns. This project performs exploratory data analysis (EDA), feature engineering, and predictive modeling using Python in Jupyter Notebook.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python 3.x
* **Data Processing:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Machine Learning:** `scikit-learn`
* **Environment:** Jupyter Notebook

---

## 📊 Key Highlights & Workflow
1. **Data Cleaning & Preprocessing:** Handled missing values, encoded categorical features, and standardized numerical inputs.
2. **Exploratory Data Analysis (EDA):** Identified key correlations, distributions, and behavioral features affecting student academic success.
3. **Machine Learning Pipeline:** Trained, evaluated, and compared predictive models to forecast academic outcomes.
